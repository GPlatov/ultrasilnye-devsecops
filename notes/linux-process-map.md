# Linux Process Map — DevOps Preparation

## Цель

Разбить Linux не как огромную тему, а как набор рабочих процессов, которые нужны для DevOps / infrastructure-направления.

Главная идея:

Linux нужно учить не “командами ради команд”, а через процессы:

- подключиться к серверу
- понять, где я нахожусь
- создать/изменить/удалить файл
- проверить сеть
- проверить сервис
- посмотреть логи
- найти ошибку
- восстановить доступ

---

## 1. Процесс: подключиться к серверу

### Что нужно понимать

Сервером обычно управляют удалённо.

Для этого используется SSH.

### Что нужно уметь

- проверить, доступен ли сервер по сети
- подключиться по SSH
- понять, под каким пользователем я зашёл
- отличить Windows PowerShell от Ubuntu через SSH

Windows:

ping 192.168.56.101 -n 4
ssh germanix@192.168.56.101
